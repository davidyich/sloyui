# Component revision queue · 2026-10-07

The canonical identity/status/group registry is `source/component-registry.json`.
IDs never change or get reused. A component can belong to multiple groups while keeping one canonical route.
`not-ready` means a reported issue is being addressed; `needs-review` means awaiting review; `ready` requires a recorded review. Newly introduced components always start as `needs-review`. Automated checks alone do not approve their visual design. Archived entries retain their ID and replacement.
