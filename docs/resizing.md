# Изменение размеров и preview стеков

`ContentLayout` сохраняет независимые width и height панелей. `collapseAt` — ширина собственного контейнера, ниже которой horizontal раскладка становится потоком; default 760, `0` отключает переход. `minContentSize` резервирует основной контент: default 240 horizontal / 120 vertical. Если весь контейнер меньше суммы минимальных размеров, доступное место важнее pane minimum: панели уменьшаются без горизонтального выпирания. Закрытая панель не занимает места. В вертикальной композиции с фиксированной доступной высотой задавайте `style.height` или `style.maxHeight` непосредственно на ContentLayout; это также надёжный контракт для браузеров без CSS Typed OM. Без ограничения высоты vertical композиция может расти.

Разделитель имеет захват 12 px; hover/focus показывает grip даже при `divider="none"`, который скрывает только декоративную линию. Drag обновляет размер один раз за animation frame и применяет последний размер на pointerup. Escape/pointercancel отменяют drag; закрытие панели очищает захват и отложенный кадр. Стрелки меняют размер на 10 px, Shift — 40 px; Home/End используют реальные доступные границы. Для понятного preview показывайте одну открытую боковую панель шириной 180 px, основной текст и карточку; вторую панель открывайте отдельным действием. Отведите preview всю ширину и вынесите настройки ниже. В узком auto-stack режиме ручки отсутствуют, поскольку панели уже занимают всю ширину.

`ResizableCard` имеет статус `needs-review`. Он сохраняет Card surface и постоянный structural boundary. `size` + `onSizeChange` — controlled режим; `defaultSize` — начальный размер uncontrolled режима, default 360×240. `onSizeChange` вызывается во время resize, `onSizeCommit` — после законченного drag или keyboard изменения. Escape/pointercancel восстанавливают начальный размер без commit. Controlled size без onSizeChange оставляет содержимое интерактивным, но отключает ручку.

Границы `minWidth/maxWidth/minHeight/maxHeight` по умолчанию 160/800/120/800. Реальная ширина родителя без padding важнее minWidth; сужение родителя ограничивает видимую ширину, сохраняя желаемый размер для последующего расширения. `step` задаёт шаг стрелок, default 10, Shift увеличивает его в четыре раза. Home/End задают минимальный/максимальный размер. `resizable=false` убирает ручку; `disabled` отключает только resize. Угол появляется на hover или focus-within, на touch виден постоянно. Содержимое прокручивается внутри body; не фиксируйте размеры внутренней Card и не обрезайте внешний structural boundary.

```tsx
const [size, setSize] = useState({ width: 360, height: 240 });
<ResizableCard label="Заметка" size={size} onSizeChange={setSize}>
  <h3>Сад идей</h3>
  <p>Drag за угол, Tab и стрелки — два способа изменить размер.</p>
</ResizableCard>
```

`ToastStack position="inline"` и `CardStack` уже резервируют внутри viewport 32 px под floating shadows и небольшое движение; не добавляйте вокруг них masked/overflow:hidden оболочку. В preview используйте обычный поток и `min-width:0`; CardStack можно ограничить `width:min(100%,520px)`. Up/down раскрытие увеличивает высоту preview, поэтому соседние блоки должны стоять ниже в потоке, а не поверх абсолютного стека. Left/right раскрытие прокручивается внутри самого viewport; при left первый элемент выравнивается с учётом обоих внутренних отступов, при up — с учётом вертикальных отступов. Collapsed горизонтальные deck помещаются по ширине. Позиции и размеры при reflow меняются согласованно: не анимируйте width/height внешнего контейнера отдельно от карточек. Swipe ограничивает визуальное смещение 24 px; порог решения по-прежнему использует полный жест. Exit — короткий сдвиг и fade, а не вылет за viewport. Toast timers приостанавливаются на hover/focus, включая controlled collapsed режим.

`tests/resizing.test.tsx` проверяет реальные bounds, live container resize, независимые оси, coalescing и pointerup, закрытие панели во время drag, controlled Card, parent fitting/restoration, Escape, read-only resize, геометрию collapsed/left-expanded стеков и controlled toast pause. `tests/browser/layout-resize.html` — отдельная страница для keyboard/drag и проверки paint bounds всех направлений; browser result не подменяется unit-тестом.
