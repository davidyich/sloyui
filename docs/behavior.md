# Общий контракт поведения 0.3

## Motion

`--cap-duration-fast: 120ms` для небольшой реакции, `normal: 180ms` для popup, `slow: 260ms` для пользовательских композиций с крупной панелью. В текущих Dialog/Drawer вход и выход используют normal. `--cap-ease-standard` = cubic-bezier(.2,0,0,1), `--cap-ease-out` = cubic-bezier(.16,1,.3,1).

Анимируйте opacity/transform. Не используйте `transition: all`, постоянный `will-change`, анимацию размеров больших поверхностей или непрерывное чтение layout. Цвет можно плавно менять на небольших контролах. В reduced motion переходы и циклы отключены; компонент остаётся понятен без движения. При выходе overlay кратко остаётся в DOM, но уже inert/aria-hidden и не принимает ввод.

## Поверхности и границы

Точный контракт и таблица поверхностей: [surface-context.md](surface-context.md).

Явный `data-surface="base" | "canvas" | "raised"` задаёт наследуемый контекст контраста. На собственном контейнере используйте соответствующую заливку, например `background: var(--cap-surface-current)`. Атрибут не анализирует и не перекрашивает произвольный фон автоматически. Встроенные панели объявляют свой слой: SidebarPanel — canvas, карточки и popup — raised.

`data-borders="off"` действует по умолчанию: декоративные границы прозрачны, нейтральные контролы отделяются более заметной заливкой. `on` возвращает границы и делает обычные заливки спокойнее. Переключение сохраняет размеры. `--cap-control-bg/hover/active`, `--cap-panel-border` и `--cap-control-border` выражают текущее состояние; focus/error indicators не выключаются.

Мягкие акцентные заливки и второстепенный текст также учитывают фактическую поверхность. Базовые 12/12/24 Figma Variables и эти runtime-правила — разные уровни системы; установка data-surface/data-borders не означает изменение модов Figma.

## Состояния

- Default/hover/active/focus-visible: семантические поверхности и видимый контур 2 px, offset 3 px.
- Disabled и loading: действие недоступно, повторный запуск блокируется. SplitButton блокирует обе части.
- Error: текстовая причина + aria-invalid + связанная подсказка. Цвет не единственный сигнал.
- Empty: причина и одно подходящее действие; отдельное состояние «ничего не найдено» для фильтра.
- Controlled state: изменения данных, сохранение, загрузка и ошибки принадлежат потребителю.

Не скрывайте actionable toast по короткому таймеру. Toast сам не управляет временем жизни. Select сохраняет native form submission, но видимый popup — собственный.

## Адаптив

- Отступ overlay до viewport — `--cap-overlay-gutter: 12px`; панели ограничены динамической высотой экрана.
- Меню имеет внутренний отступ 6 px, popover — 12 px, body диалога — 16 px; радиусы 7/12/16 px соответственно уровням.
- Touch targets — минимум 44 px при coarse pointer. Компактные desktop controls сохраняют размеры 22/28/32/36 px. `size` у ActionBar/ButtonGroup/SplitButton согласует высоты вложенных кнопок и полей; вложенная группа может переопределить размер. Внутренний padding ButtonGroup включён в его внешнюю высоту. `Popover.size` меняет только trigger.
- Контент перестраивается в одну колонку; канбан/табы/таблицы прокручиваются внутри ограниченного контейнера.
- ScrollArea оставляет нативные wheel/touch/keyboard и overscroll containment. `scrollbar="auto"` использует тонкую полосу по правилам браузера; `hidden` скрывает её. Горизонтальный режим по умолчанию hidden, вертикальный и both — auto. Краевые маски открывают фон, а не накладывают цветную тень; они активны только со стороны скрытого контента. `shadows={false}` отключает маски.
- Не задавайте фиксированную ширину страницы в библиотеке. Layout приложения — задача потребителя.

## Клавиатура и popup

Меню — стрелки/Home/End/typeahead/Enter/Escape. Tabs — стрелки/Home/End. ActionBar — один tab stop, стрелки между действиями. Диалог удерживает Tab, отключает фон и возвращает фокус. Вложенный Escape закрывает верхний слой. Tooltip доступен по focus и hover. Calendar — стрелки, Home/End, PageUp/PageDown, Enter/Space.

Portal переносит ближайшие `data-theme`, `data-accent`/`data-color` и `data-borders`. Его собственная поверхность — `raised`; размер панели инструментов остаётся у триггера и не переходит в содержимое popup. Устанавливайте глобальную тему на html, а локальный акцент на общий контейнер компонентов. Проверяйте длинный текст, пустые данные и небольшой viewport в конкретном приложении.

## Каталог

Каждый из 59 компонентов имеет отдельную страницу `#ComponentName` с вариантами и состояниями, например `#ActionBar` или `#Select`. Боковая навигация сгруппирована по назначению; общие настройки темы, рамок и поверхности позволяют проверить одни и те же компоненты в разных контекстах. Перечень проверенных сценариев находится в `docs/verification.md`; новые правила сами по себе не являются результатом проверки.
