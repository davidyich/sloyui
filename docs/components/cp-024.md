# SegmentedControl

cp-024 · Индивидуальная инструкция

## Когда выбрать

Для быстрого переключения между несколькими короткими равноценными режимами: список, сетка, доска.

## Как применять

Передайте `options` с уникальными значениями, обязательный `label`, текущий `value` и `onValueChange`. `fullWidth` распределяет доступную ширину; вариант выбирайте через `variant`.

## Состояния и доступность

Выбор отражает текущий режим. Проверяйте клавиатурный переход и длинные локализованные подписи; для большого списка используйте Select.

## Делать

- Держать варианты одного уровня и одной задачи.
- Показывать действительно активный режим из состояния приложения.

## Не делать

- Не смешивать команды «Удалить» и «Создать» с режимами просмотра.
- Не помещать десять длинных пунктов в одну тесную строку.
