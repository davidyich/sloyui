# ButtonGroup

cp-045 · Индивидуальная инструкция

## Когда выбрать

Для нескольких связанных кнопок одного назначения: форматирования, набора соседних действий.

## Как применять

Передайте реальные Button в `children`, задайте `label`, при необходимости `attached`, `appearance` и `orientation`. `size` задаёт внешнюю высоту и может переопределять размер окружающей ActionBar; `prefix` добавляет статичный контекст.

## Состояния и доступность

Кнопки остаются отдельными нативными элементами. Группа сама не хранит выбранное значение; для одного выбора из режимов используйте SegmentedControl.

## Делать

- Объединять кнопки одной задачи и согласовывать размер всей группы.
- Использовать `attached` для визуально цельной последовательности.

## Не делать

- Не вкладывать одну кнопку в другую ради общей рамки.
- Не ожидать радиовыбора и сохранённого состояния от ButtonGroup.
