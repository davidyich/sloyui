# FilterToolbar

cp-075 · Индивидуальная инструкция

## Когда выбрать

Для составления фильтров над таблицей или списком: поле, оператор, значение и общий поиск.

## Как применять

Передайте `fields` типа FilterField, `filters` типа ActiveFilter и `onFiltersChange`. Поисковую строку задавайте отдельно через `query`/`onQueryChange`; `label` называет панель. Применение условий к данным остаётся в приложении.

## Состояния и доступность

Проверяйте добавление, изменение, удаление и сброс фильтра без потери фокуса. Пустая выдача должна объяснять текущие ограничения и предлагать очистку.

## Делать

- Синхронизировать панель с фактически применёнными условиями.
- При серверном поиске согласовывать запрос и страницу результатов.

## Не делать

- Не показывать выбранный фильтр, который ещё не применяется к данным.
- Не терять остальные условия при изменении одной ActiveFilter.
