# ToastStack

cp-077 · Индивидуальная инструкция

## Когда выбрать

Для нескольких связанных уведомлений, которые нужно свернуть в компактную стопку и раскрыть по запросу.

## Как применять

Передайте `items` со стабильными ID и `onDismiss(id)`. `position`, `scope` и `expandDirection` задают расположение; `expanded`/`onExpandedChange` — раскрытие. `limit` ограничивает показ, `showExpandHint` — встроенную подсказку количества. При `false` отдельная стрелка не рисуется: hover/focus и касание переднего тоста раскрывают стопку, переключатель остаётся доступен с клавиатуры.

## Состояния и доступность

Скрытые actionable и pending-уведомления не должны истекать до использования. При скрытой подсказке остаётся доступная кнопка раскрытия. Нативная прокрутка сохраняется без видимой полосы.

## Делать

- Располагать стопку так, чтобы она не закрывала основное действие.
- Сохранять уведомление с «Отменить» до возможности прочитать и нажать его.

## Не делать

- Не удалять задние уведомления только ради компактной геометрии.
- Не включать разные независимые таймеры, игнорирующие раскрытие и pending-состояние.
