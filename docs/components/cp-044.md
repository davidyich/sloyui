# ScrollArea

cp-044 · Индивидуальная инструкция

## Когда выбрать

Для области с ограниченным размером и собственной прокруткой: дерева, таблицы, списка или истории.

## Как применять

Ограничьте прокручиваемую ось, выберите `axis`, `scrollbar` и `fade`. `ref` указывает на viewport. Действия с внешней тенью передавайте в `floating`; высота этого слота резервирует место в контенте.

## Состояния и доступность

Колесо, touch и клавиатурная прокрутка остаются нативными. Горизонтальная полоса по умолчанию скрыта, вертикальная — auto. Fade показывает края реальной поверхности и исчезает без overflow.

## Делать

- Для FloatingActionBar использовать слот `floating`, чтобы не обрезать тень.
- Давать области понятный `label`, особенно при нескольких независимых списках.

## Не делать

- Не отключать прокрутку, чтобы спрятать обрезанные действия.
- Не накладывать floating-панель поверх последней строки без свободного места.
