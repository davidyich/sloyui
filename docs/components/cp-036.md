# CodeBlock

cp-036 · Индивидуальная инструкция

## Когда выбрать

Для читаемого примера кода, команды установки или нескольких вариантов одной инструкции.

## Как применять

Код передайте строкой в `children` или через `tabs` с активным `tab`. `headerVariant="unified"` объединяет шапку с телом; `variant` выбирает подложку и границу. Для редактора используйте `editor`, не вложенный framed pre.

## Состояния и доступность

Копирование использует точный исходник активного варианта. `tabsLabel` называет переключатель. Проверяйте переносы `wrap`, длинную строку и открытое меню на узкой ширине.

## Делать

- Давать командам разные подписи в `tabs`, сохраняя исходник без декоративных префиксов.
- Использовать `color="inherit"` для локального акцента.

## Не делать

- Не добавлять номера строк или знак `$` в строку, которую пользователь копирует.
- Не обрезать действия шапки через overflow ради длинного кода.
