# DataTable

cp-074 · Индивидуальная инструкция

## Когда выбрать

Для интерактивной таблицы с сортировкой, выбором строк, поиском и пагинацией. Для небольшой статичной таблицы достаточно Table.

## Как применять

Передайте `rows`, `columns`, `rowId` и `label`. Управляйте `sort`/`onSortChange`, `selectedIds`/`onSelectedIdsChange` и `page`/`onPageChange`; включите `selectable` для выбора строк; `surface` задаёт контекст при необходимости. Фильтрацию серверных данных выполняет приложение.

## Состояния и доступность

ID строки остаётся стабильным при сортировке и смене страницы. Проверяйте доступные заголовки, выбранные строки, пустой результат и состояние загрузки вокруг таблицы. Дочерние действия в ячейках должны иметь собственные подписи.

## Делать

- Сохранять выбранные ID отдельно от визуального индекса строки.
- Давать колонкам конкретные подписи и форматировать значения по типу данных.

## Не делать

- Не использовать индекс массива в `rowId` после сортировки.
- Не считать сортировку текущей страницы сортировкой всего серверного набора.
