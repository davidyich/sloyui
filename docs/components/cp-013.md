# Separator

cp-013 · Индивидуальная инструкция

## Когда выбрать

Для разделения соседних групп, если одних отступов недостаточно. Не нужен между каждой строкой списка.

## Как применять

Выберите `orientation`, при необходимости задайте `length` и `contrast`. `reveal="hover"` уменьшает постоянную визуальную нагрузку, но не меняет структуру содержимого.

## Состояния и доступность

Компонент рендерит `hr` с направлением. Отсутствие видимой линии не должно скрывать единственную подсказку о группировке; заголовки и отступы сохраняют смысл.

## Делать

- Ставить разделитель между группами разных действий в длинной панели.
- Для вертикальной линии задавать осмысленную высоту через `length`.

## Не делать

- Не использовать Separator как интерактивную ручку изменения размера.
- Не исправлять плоскую иерархию десятками линий вместо группировки.
