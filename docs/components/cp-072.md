# ValueScrubber

cp-072 · Индивидуальная инструкция

## Когда выбрать

Для частого компактного изменения числа непосредственно рядом с визуальным объектом: размера, масштаба, значения параметра.

## Как применять

Передайте `value`, `onValueChange`, `label`, пределы и `step`. `formatValue` оформляет число, `orientation` задаёт направление. Для прямого текстового ввода добавьте NumberField с тем же значением.

## Состояния и доступность

Поддерживаются стрелки, Home/End, Alt+pointer, Shift для точной настройки; Escape и cancellation откатывают жест. Вправо и вверх увеличивают число. `disabled` блокирует изменение.

## Делать

- Давать понятные единицы и пределы параметра.
- Оставлять точный ввод доступным рядом, если нужны большие значения.

## Не делать

- Не требовать знания скрытого Alt-жеста как единственного способа изменения.
- Не сохранять отменённый жест как финальное изменение параметра.
