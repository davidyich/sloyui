# Kbd

cp-012 · Индивидуальная инструкция

## Когда выбрать

Для отображения клавиши или сочетания, которое приложение уже поддерживает.

## Как применять

Передайте надпись клавиши в `children`: `⌘`, `K`, `Esc`. Несколько Kbd можно объединить в сочетание; регистрация обработчика клавиатуры остаётся в приложении.

## Состояния и доступность

Рендерится нативный `kbd`; это текстовое пояснение, а не интерактивный элемент. Показывайте сочетание для текущей платформы и доступную альтернативу действию.

## Делать

- В Tooltip указывать `shortcut`, когда нужна готовая композиция клавиш.
- Согласовывать подсказку с реально зарегистрированным сочетанием.

## Не делать

- Не обещать сочетание, которое работает только при случайном фокусе.
- Не добавлять Kbd обработчик клика и роль кнопки.
