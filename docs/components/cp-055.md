# MarkdownPreview

cp-055 · Индивидуальная инструкция

## Когда выбрать

Для безопасного чтения ограниченного Markdown: инструкции, комментария или описания.

## Как применять

Передайте строку в `value`; `headingOffset` согласует уровни заголовков с родительской страницей. Поддерживаются основные блоки и inline-форматирование; это не полный CommonMark-парсер.

## Состояния и доступность

HTML экранируется, протоколы ссылок фильтруются. Для редактирования выберите RichTextEditor с Markdown bridge или MarkdownEditorV2; проверяйте смысловую иерархию заголовков.

## Делать

- Сохранять исходную строку отдельно от отображения.
- Проверять ссылки, списки, код и заголовки на реальном тексте инструкции.

## Не делать

- Не ожидать исполнения HTML или встроенного JavaScript.
- Не обещать точную поддержку всех расширений Markdown без проверки.
