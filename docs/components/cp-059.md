# TaskCard

cp-059 · Индивидуальная инструкция

## Когда выбрать

Для задачи с завершением, открытием, метаданными и меню действий.

## Как применять

Передайте `title`, `completed` и `onCompletedChange`. `menuItems` добавляет команды, `onOpen` — открытие. Слоты и блоки ContentCard позволяют менять состав без отдельного форка; `dragHandle` связывает переупорядочивание.

## Состояния и доступность

Завершение, заголовок и меню — независимые контролы. Приложение хранит `completed` и обрабатывает отказ сервера; скрытие блока не должно терять данные задачи.

## Делать

- Согласовывать состояние Checkbox с сохранённым результатом.
- Для приоритета или срока использовать metadata и текстовую метку.

## Не делать

- Не использовать зачёркнутый заголовок как единственный признак завершения.
- Не открывать задачу при клике на её завершение или меню.
