# AnnouncementBar

cp-078 · Индивидуальная инструкция

## Когда выбрать

Для общего объявления продукту: обновления, периода обслуживания или нового доступного сценария.

## Как применять

Передайте `messages`, `label`, при необходимости `open`/`onOpenChange` и `index`/`onIndexChange`. `autoPlay`, `interval` и `controls` управляют сменой сообщений; `onAction` и `onCountdownEnd` делегируют события приложению.

## Состояния и доступность

Важное объявление должно быть читаемым без ожидания карусели. Закрытие и переключение доступны с клавиатуры; обратный отсчёт не должен быть единственным источником срока.

## Делать

- В каталоге оставлять dismiss только до reload, не назначая persistent ID объявления.
- Давать действию конкретное назначение, например «Открыть изменения».

## Не делать

- Не использовать общий баннер для ошибок отдельного поля.
- Не запускать слишком быструю автоматическую смену длинных сообщений.
