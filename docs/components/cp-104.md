# PopupSelect

cp-104 · Индивидуальная инструкция

## Когда выбрать

Для одного значения из списка с опциональным поиском и богатым статичным представлением вариантов, когда нужен компактный триггер.

## Как применять

Передайте `options` типа PopupSelectOption, `label`, `value`/`onValueChange`. `triggerContent` меняет закрытое отображение, `popupWidth` — независимую ширину списка; `searchPlaceholder`, `emptyMessage`, `hint` и `error` объясняют состояние. `name` сохраняет форму. Поиск выключен по умолчанию; `searchable` включает его, а `searchPlacement="inline" | "separate"` выбирает встроенную строку или отдельное поле.

## Состояния и доступность

Триггер открывает немодальный dialog с listbox; combobox появляется только при `searchable`. Без поиска фокус получает список, набор символов выбирает совпадающий пункт. Стрелки/Home/End пропускают disabled, Enter выбирает, Escape возвращает фокус; Tab закрывает и продолжает обход. Портал сохраняет локальные контексты.

## Делать

- Добавлять aliases и descriptions для поиска по знакомым пользователю словам.
- Оставлять `label` доступным даже при `showLabel={false}`.

## Не делать

- Не добавлять интерактивные элементы в декоративные слоты пунктов.
- Не считать `popupWidth` гарантией выхода за пределы viewport.
