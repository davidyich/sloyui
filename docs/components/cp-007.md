# TextAction

cp-007 · Индивидуальная инструкция

## Когда выбрать

Для текстового перехода или тихого вторичного действия внутри описания и панели.

## Как применять

С `href` компонент рендерит ссылку; без `href` — кнопку. Передавайте адрес для навигации, `onClick` для операции и содержательный текст в `children`; `type="submit"` задаётся явно при отправке формы.

## Состояния и доступность

Ссылка и кнопка сохраняют свои нативные клавиатурные правила. Ссылка должна объяснять назначение вне окружающего текста, например «Открыть настройки проекта».

## Делать

- Использовать адрес для перехода, сохраняя открытие в новой вкладке.
- Писать короткую подпись действия вместо «Нажмите здесь».

## Не делать

- Не имитировать навигацию кнопкой с `location.href`, если есть адрес.
- Не использовать тихий TextAction для единственного главного действия сложной формы.
