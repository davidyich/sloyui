# Checkbox

cp-020 · Индивидуальная инструкция

## Когда выбрать

Для независимого булевого выбора и множественного выбора элементов списка.

## Как применять

Передайте `label`; храните состояние через `checked` и `onChange`, либо начните с `defaultChecked`. `name` и `value` задают значение формы. `indeterminate` показывает частично выбранную группу.

## Состояния и доступность

Нативный checkbox переключается Space. `disabled` блокирует действие; промежуточное состояние не является третьим бизнес-значением без логики приложения.

## Делать

- Для «Выбрать всё» вычислять `indeterminate` из выбранных дочерних строк.
- Давать каждому пункту собственную понятную подпись.

## Не делать

- Не использовать Checkbox для взаимоисключающих вариантов — нужен RadioGroup.
- Не считать `indeterminate` сохранённым подтверждением согласия.
