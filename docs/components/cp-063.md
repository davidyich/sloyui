# TreeView

cp-063 · Индивидуальная инструкция

## Когда выбрать

Для иерархического выбора узла: проекта, раздела или папки с вложенными элементами.

## Как применять

Передайте `nodes` типа TreeNode с уникальными ID и `label`. `selectedId`/`onSelect` задают текущий узел; `expandedIds`/`onExpandedChange` — раскрытие, `defaultExpandedIds` — начальное состояние. `showGuides` рисует связи.

## Состояния и доступность

Проверяйте стрелочную навигацию, раскрытие и возвращение к родителю. Выбор и раскрытие — разные состояния; приложение сохраняет нужный узел и загружает данные.

## Делать

- Оставлять стабильные ID при переименовании и перемещении узла.
- Раскрывать путь к выбранному узлу при восстановлении навигации.

## Не делать

- Не определять идентичность узла его видимым названием.
- Не вкладывать дополнительные кнопки в кнопочное содержимое строки дерева.
