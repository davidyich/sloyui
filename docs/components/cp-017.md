# Textarea

cp-017 · Индивидуальная инструкция

## Когда выбрать

Для многострочного простого текста: комментария, описания, заметки без форматирования.

## Как применять

Передайте `label`, `rows` и при необходимости `hint` или `error`. Храните текст через `value` и `onChange`; `name` нужен для формы. Для структурированного форматирования используйте RichTextEditor.

## Состояния и доступность

Сохраняйте переносы строк и видимый фокус. `disabled` блокирует ввод, `readOnly` оставляет текст доступным. Метка не должна исчезать при появлении содержимого.

## Делать

- Подбирать `rows` по ожидаемому объёму текста.
- Показывать ошибку с конкретным ограничением длины и способом исправления.

## Не делать

- Не заменять Textarea однострочным Input для длинных комментариев.
- Не добавлять Field с той же подписью поверх встроенного `label`.
