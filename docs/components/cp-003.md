# Icon

cp-003 · Индивидуальная инструкция

## Когда выбрать

Для визуального дополнения подписи или статуса, когда смысл уже выражен текстом.

## Как применять

Передайте `name` из экспортируемых имён или непосредственно импортированный Lucide-компонент; `size` задаётся числом. Для действия используйте IconButton, а для цветной подложки — IconBox.

## Состояния и доступность

По умолчанию SVG декоративный: `aria-hidden="true"` и `focusable="false"`. Значимый статус должен иметь текстовую подпись вне иконки.

## Делать

- Повторять один символ для одного смысла во всём продукте.
- Выбирать иконку через визуальный IconPicker при настройке пользователем.

## Не делать

- Не ожидать загрузки произвольного строкового имени, которого нет в IconSource.
- Не передавать смысл ошибки только цветом или рисунком.
