# ReorderableList

cp-057 · Индивидуальная инструкция

## Когда выбрать

Для изменения вертикального порядка небольшого набора карточек или строк внутри одной коллекции.

## Как применять

Передайте `items` со стабильными уникальными ID, `getItemLabel`, `renderItem` и `onOrderChange`. При `handlePlacement="custom"` используйте полученный handle в `dragHandle` карточки. Новый порядок сохраняет приложение.

## Состояния и доступность

Pointer-drag начинается только с ручки. Стрелки, Home/End и меню перемещения дают альтернативы; Escape отменяет незавершённое перетаскивание. `disabled` блокирует переупорядочивание.

## Делать

- Сохранять новый массив после `onOrderChange` и проверять результат после перезагрузки.
- Давать ручке понятное имя из `getItemLabel`.

## Не делать

- Не использовать индекс массива как стабильный ID.
- Не начинать drag с любого клика по форме или тексту внутри карточки.
