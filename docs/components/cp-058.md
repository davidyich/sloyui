# ContentCard

cp-058 · Индивидуальная инструкция

## Когда выбрать

Для карточки с независимыми блоками, действиями, открытием и выбором: записи, материала или результата поиска.

## Как применять

Используйте `title`, `metadata`, `cover`, `actions`, `footer` и расширяемые `blocks`. `blockOrder` и `hiddenBlocks` обращаются к стабильным ID; `onOpen` делает заголовок действием. Выбор включается через `selectable`.

## Состояния и доступность

Корень — article, поэтому независимые кнопки и ссылки допустимы. `selectionLabel` называет Checkbox; `selected`/`onSelectedChange` управляют выбором. Surface родителя сохраняется, подложка — `surface/block`.

## Делать

- Переупорядочивать блоки по ID, сохраняя данные скрытых блоков.
- Для смешанных ориентаций не растягивать все карточки до самого высокого соседа.

## Не делать

- Не делать всю карточку кнопкой поверх её собственных действий.
- Не считать `onSelectedChange` достаточным включением выбора при `selectable={false}`.
