# CollectionRow

cp-027 · Индивидуальная инструкция

## Когда выбрать

Для компактного открытия коллекции или объекта в вертикальном списке.

## Как применять

Передайте `title`, необязательные `icon`, `color` и `meta`, обработчик `onClick`. `meta` подходит для количества или времени обновления; `disabled` отражает недоступность.

## Состояния и доступность

Корневой элемент — кнопка с нативной активацией. Метаданные не должны добавлять вложенные интерактивные элементы; действия списка размещайте рядом отдельными кнопками.

## Делать

- Сохранять одинаковую структуру названия и метаданных во всех строках.
- Проверять длинные названия без потери различия между коллекциями.

## Не делать

- Не вкладывать Menu или TextAction в `meta` кнопочной строки.
- Не использовать CollectionRow как редактор свойств — нужен PropertyRow.
