# Slider2D

cp-106 · Индивидуальная инструкция

## Когда выбрать

Для двух взаимосвязанных числовых параметров: насыщенности и плотности, позиции, характера заливки. Оси остаются независимыми числами, а не готовыми пресетами.

## Как применять

`value` содержит `{x, y}`. Каждая ось `x` / `y` имеет `label`, `min`, `max`, `step`, `fineStep`, `startLabel`, `endLabel`, `reversed`, `suffix`, `formatValue`. X растёт вправо, Y вверх; `reversed` меняет направление одной оси. `showGrid` управляет сеткой; `showFields` по умолчанию выключен и показывает два точных NumberField только при необходимости. `size` задаёт размер полей и общий радиус площадки по геометрии полей того же размера.

Границы поля следуют `data-borders`: семантическая рамка включается вместе с остальными контролами и не меняет размеры.

## Состояния и доступность

Наведение и нажатие меняют семантическую поверхность площадки; клавиатурный фокус остаётся видимым и следует её скруглению. Указатель меняет параметры напрямую: движения объединяются в один кадр без инерции. Отпускание записывает последнюю координату и вызывает `onValueCommit`. Escape и отмена указателя восстанавливают оба исходных числа. Стрелки меняют соответствующую ось, Shift включает `fineStep`, Home/End задают обе границы. Если `showFields=false`, обе оси доступны как native ranges для вспомогательных технологий.

## Делать

- Давать каждой оси собственное понятное имя и диапазон.
- Для плотности, растущей вниз, ставить `y.reversed=true`.
- Использовать `showFields`, когда важен точный ввод.
- Сохранять итог через `onValueCommit`.

## Не делать

- Не заменять два независимых числовых значения одним текстовым пресетом.
- Не переименовывать концы оси без изменения направления.
- Не заставлять пользователя попадать указателем в единственную точную координату.
- Не добавлять анимацию, которая задерживает значение относительно указателя.
