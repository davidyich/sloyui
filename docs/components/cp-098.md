# FileTree

cp-098 · Индивидуальная инструкция

## Когда выбрать

Для навигации по файлам и папкам с дополнительным предпросмотром выбранного файла.

## Как применять

Передайте `nodes` типа FileTreeNode, `label` и выбор через `selectedId`/`onSelect` либо `defaultSelectedId`. `expandedIds` управляет раскрытием; `showPreview`, `showGuides`, `emptyLabel` настраивают представление.

## Состояния и доступность

TreeView обеспечивает клавиатурную навигацию и стабильные ID. Действия выбранного файла и preview находятся вне кнопок строк. Загрузка содержимого и операции с файлами остаются в приложении.

## Делать

- Сохранять ID файла при переименовании и переносе.
- Для пустой папки показывать осмысленный emptyLabel и доступное добавление.

## Не делать

- Не вкладывать удаление или загрузку в кнопку строки дерева.
- Не считать строку пути неизменяемым ID, если файл может перемещаться.
