# NumberField

cp-071 · Индивидуальная инструкция

## Когда выбрать

Для точного числового значения с вводом и шаговыми кнопками: количества, размера, отступа.

## Как применять

Передайте `label`, `value`/`onValueChange`, `min`, `max` и `step`. `largeStep` задаёт большой шаг; `prefix` и `suffix` показывают контекст и единицы. `scrubbable={false}` выключает дополнительное Alt-перетаскивание.

## Состояния и доступность

Нативный number-input сохраняет ввод, стрелки и форму; собственные steppers заменяют визуальные browser-spinners. Ошибка приходит через `error`. Промежуточный ввод сохраняется; при выходе из поля значение ограничивается заданными пределами.

## Делать

- Показывать единицы рядом с числом через `suffix`.
- Выбирать шаг по предметной области, например 1 для количества и 0.1 для масштаба.

## Не делать

- Не создавать собственные +/- div вместо готовых контролов.
- Не использовать NumberField для идентификатора с ведущими нулями — нужен Input.
