# DailyHeader

cp-062 · Индивидуальная инструкция

## Когда выбрать

Для заголовка дневной заметки или плана с датой, неделей, метками и действиями.

## Как применять

Передайте локальную строку `date`, при необходимости `locale`, `showWeek`, `tags` и `actions`. `headingLevel` согласует заголовок с документом; ISO-номер недели вычисляется компонентом.

## Состояния и доступность

LocaleProvider задаёт язык интерфейса и формат по умолчанию; явный `locale` меняет формат даты. Кнопки в `actions` должны иметь собственные доступные подписи.

## Делать

- Использовать `headingLevel={1}` только для главного заголовка страницы.
- Проверять переход года, где номер ISO-недели отличается от календарного года.

## Не делать

- Не преобразовывать дату дневной заметки через UTC с потерей дня.
- Не подменять фактическую дату страницы сегодняшней датой при каждом рендере.
