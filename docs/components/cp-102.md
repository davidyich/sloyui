# MarkdownEditorV2

cp-102 · Индивидуальная инструкция

## Когда выбрать

Для редактора, где приложение уже хранит Markdown-строку и нужны контекстные действия форматирования.

## Как применять

Храните `value`/`onValueChange` как строку, задайте `label`, при необходимости `placeholder`, `toolbarSize`. `onCommentRequest` передаёт выделенный текст приложению. Для самостоятельного структурированного документа используйте RichTextEditor.

## Состояния и доступность

`readOnly` оставляет чтение, `disabled` блокирует редактирование. Неподдерживаемый синтаксис сохраняется редактируемым исходником. Сохранение строки и создание обсуждений выполняет приложение.

## Делать

- Проверять round-trip реального Markdown, включая неподдерживаемые блоки.
- Сохранять черновик строки до подтверждения сервером.

## Не делать

- Не путать канонический MarkdownEditorV2 с архивным alias MarkdownEditor.
- Не считать `onCommentRequest` встроенным хранением комментариев.
