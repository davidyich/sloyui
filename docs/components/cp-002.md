# IconButton

cp-002 · Индивидуальная инструкция

## Когда выбрать

Для знакомого компактного действия: закрыть панель, открыть поиск, скопировать значение. Неочевидное действие лучше показать обычной Button с текстом.

## Как применять

Укажите обязательные `icon` и `label`, например `icon="close"`, `label="Закрыть предпросмотр"`. Размер и вариант задаются через `size` и `variant`; действие — через `onClick`.

## Состояния и доступность

`label` становится доступным именем кнопки. `loading` и `disabled` блокируют активацию. Сохраняйте видимый фокус; Tooltip может пояснять действие, но не заменяет имя.

## Делать

- Называть результат действия: «Удалить вложение», а не «Корзина».
- Проверять доступность маленькой кнопки на сенсорном экране.

## Не делать

- Не ставить `label="Иконка"` или пустую подпись.
- Не использовать декоративный Icon с обработчиком вместо IconButton.
