# Progress

cp-015 · Индивидуальная инструкция

## Когда выбрать

Для операции с измеримым прогрессом: загрузки файла, импорта или обработки известного набора.

## Как применять

Передайте `value` от 0 до 100 и обязательный `label`, например «Импорт контактов». Значение вычисляет приложение; завершение и ошибка отображаются отдельно.

## Состояния и доступность

Компонент имеет `role="progressbar"` и доступное числовое значение; нечисловые значения приводятся к 0. Для неизвестной длительности используйте Spinner.

## Делать

- Вычислять процент из реально выполненной части работы.
- Оставлять название операции рядом с полосой, особенно при нескольких загрузках.

## Не делать

- Не анимировать случайный процент до 90%, если данных о прогрессе нет.
- Не считать `value={100}` подтверждением успешного серверного результата.
