# Switch

cp-022 · Индивидуальная инструкция

## Когда выбрать

Для настройки, которая включается или выключается сразу: уведомления, видимость, автоматический режим.

## Как применять

Передайте `label`, `checked` и `onChange`. `variant="neutral"` оставляет спокойное оформление, `accent` выделяет включённость; `color` задаёт акцент при необходимости.

## Состояния и доступность

Сохраняйте доступную подпись и клавиатурное переключение. На время серверного изменения можно блокировать через `disabled`; при отказе верните подтверждённое значение и объясните ошибку.

## Делать

- Формулировать подпись как настройку: «Уведомления о комментариях».
- Отражать подтверждённое состояние при ошибке сохранения.

## Не делать

- Не использовать Switch для действия «Сохранить» или принятия обязательного соглашения.
- Не менять смысл подписи между включённым и выключенным состоянием.
