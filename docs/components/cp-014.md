# Skeleton

cp-014 · Индивидуальная инструкция

## Когда выбрать

Для первоначальной загрузки блока, форма которого заранее известна: строки, карточки, аватар.

## Как применять

Задайте геометрию через композицию и `className` или `style`. После получения данных замените Skeleton реальным содержимым; состояние запроса хранится вне компонента.

## Состояния и доступность

Skeleton скрыт от вспомогательных технологий. Родитель сообщает загрузку через `aria-busy` или отдельный status; при ошибке каркас заменяется сообщением.

## Делать

- Повторять основные размеры ожидаемого контента, чтобы уменьшить скачок раскладки.
- Использовать один статус загрузки для всей группы каркасов.

## Не делать

- Не оставлять Skeleton как пустое состояние после успешного ответа.
- Не размещать внутри него интерактивные элементы или смысловой текст.
