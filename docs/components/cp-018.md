# Select

cp-018 · Индивидуальная инструкция

## Когда выбрать

Для выбора одного значения из ограниченного известного списка. Для большого списка с поиском выберите ComboBox или PopupSelect.

## Как применять

Передайте `options` с уникальными `value` и текстовыми `label`, затем `value` и `onValueChange`. `label`, `hint` и `error` оформляют поле; `name` связывает скрытый select с формой. `meta` дополняет пункт, `triggerLabel` меняет только закрытую подпись.

Для плотных инспекторов используйте `appearance="parameter"`: единый trigger содержит подпись слева и выбранное значение справа. Не добавляйте повторный label снаружи.

## Состояния и доступность

Стрелки, Home/End и поиск по первым буквам выбирают пункты; Escape закрывает список. Disabled-пункты пропускаются. Native backing select сохраняет отправку, required и reset.

## Делать

- Оставлять `label` пункта понятным для поиска по первым буквам.
- Включать `scrubbable` только там, где Alt+перетаскивание ускоряет частый выбор.

## Не делать

- Не размещать кнопки в декоративном `meta` пункта.
- Не передавать выбранное значение, которого нет в списке.
