# KanbanColumn

cp-060 · Индивидуальная инструкция

## Когда выбрать

Для одной полосы доски с названием, количеством, карточками и локальными действиями.

## Как применять

Укажите `title`, реальный `count`, слоты `action`, `footer`, `emptyState`. `variant="framed"` добавляет общую рамку; `color` относится к заголовку и счётчику. Содержимое передаётся в `children`.

## Состояния и доступность

Колонка сама не переносит карточки — управляемые переносы даёт KanbanBoard. Пустая колонка должна объяснять возможность добавления или перемещения задачи; Surface приходит из композиции.

## Делать

- Считать количество из фактических задач колонки.
- Давать кнопке добавления название с нужным статусом или этапом.

## Не делать

- Не окрашивать все карточки цветом этапа через ручные CSS overrides.
- Не ожидать drag-and-drop от отдельной KanbanColumn.
