# ColorPicker

cp-070 · Индивидуальная инструкция

## Когда выбрать

Для пользовательского значения цвета: заливки объекта, темы или собственного набора образцов.

## Как применять

Укажите `label`, `value`/`onValueChange`, при необходимости `format`, `palette` и `background`. Сохранённые образцы управляются отдельно через `swatches`/`onSwatchesChange`; `showRecent` показывает недавние цвета.

## Состояния и доступность

Текстовый ввод, палитра и визуальное поле должны оставаться доступными. `disabled`, `description` и `error` объясняют ограничения. Проверяйте прозрачность на реальном фоне; валидация и сохранение — в приложении.

## Делать

- Использовать `background` для честного предпросмотра полупрозрачного цвета.
- Для системных ролей предлагать семантический выбор, когда свободный цвет не нужен.

## Не делать

- Не заменять компонент браузерным `input type="color"`.
- Не записывать пользовательский цвет в CSS всей страницы вместо локальной настройки.
