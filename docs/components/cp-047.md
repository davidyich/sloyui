# ActionBar

cp-047 · Индивидуальная инструкция

## Когда выбрать

Для компактной панели последовательных действий: инструменты редактора или операции над выборкой.

## Как применять

Передайте кнопки в `children`, задайте `label`, `size` и `orientation`. По умолчанию действует roving focus; `rovingFocus={false}` нужен для формы или сложных полей. Вложенный ButtonGroup может задавать свой размер.

## Состояния и доступность

Стрелки и Home/End переходят между enabled-действиями при одной Tab-остановке. Смешанные формы должны сохранять привычное управление внутри поля.

## Делать

- Использовать roving focus для однородной группы кнопок.
- Выключать его, когда стрелки нужны вложенному текстовому или числовому полю.

## Не делать

- Не перехватывать стрелки редактора ради навигации по панели.
- Не заменять ActionBar всем заголовком страницы с несвязанными блоками.
