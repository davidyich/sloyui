# Card

cp-025 · Индивидуальная инструкция

## Когда выбрать

Для статичной группы содержимого, которой нужна локальная подложка. Для карточки с независимыми действиями используйте ContentCard.

## Как применять

Передайте содержимое в `children`. Card сохраняет Surface родителя: default рисует `surface/block`, subtle — `surface/bg`, elevated добавляет тень. `data-surface` задавайте явно в композиции только при смене контекста.

## Состояния и доступность

Card не становится кнопкой автоматически. Структурная граница `.cap-surface-boundary` остаётся видимой при выключенных декоративных границах, в том числе у совпадающих вложенных поверхностей.

## Делать

- Использовать заголовок и отступы, чтобы связать содержимое в группу.
- Сохранять контекст родителя для дочерних контролов внутри карточки.

## Не делать

- Не делать все строки страницы отдельными вложенными Card.
- Не назначать `onClick` всему контейнеру с интерактивными дочерними элементами.
