# Breadcrumbs

cp-030 · Индивидуальная инструкция

## Когда выбрать

Для ориентации в иерархии и возврата к родительским страницам.

## Как применять

Передайте `items` с `label` и `href` для доступных предков; текущий пункт оставьте без адреса. Для сокращённого предка укажите `collapsed: true`: он отображается как многоточие, сохраняя полную доступную подпись и ссылку. `label` компонента даёт имя навигационной области.

## Состояния и доступность

Ссылки сохраняют нативное открытие и клавиатурный фокус. Названия должны быть различимыми; последний пункт обозначает текущую страницу, а не отдельную команду.

## Делать

- Показывать реальный путь объекта в продукте.
- Для длинного пути сокращать композицию осмысленно, сохраняя ближайшего родителя.

## Не делать

- Не помещать в цепочку действия «Сохранить» и «Удалить».
- Не подменять иерархию историей последних посещений.
