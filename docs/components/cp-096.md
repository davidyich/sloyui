# Chip

cp-096 · Индивидуальная инструкция

## Когда выбрать

Для нейтрального выбора, фильтра или удаляемого значения. Для цветной метки типа объекта используйте Tag.

## Как применять

Передайте подпись, при необходимости `icon`, `count`, `selected`, `onClick` и `onRemove`. `action` даёт подписанное отдельное действие; `interactive={false}` делает все слоты статичными. `shape` регулирует геометрию.

## Состояния и доступность

Выбор и удаление — независимые кнопки. `disabled` блокирует оба; `selected` приходит из состояния приложения. Chip остаётся нейтральным независимо от локального акцента.

## Делать

- Отражать фактически применённый фильтр через `selected`.
- Для удаления пользовательского значения сохранять понятное имя действия.

## Не делать

- Не искать `color` prop для окраски Chip в цвет категории.
- Не вкладывать кнопку закрытия в кликабельную подпись вручную.
