# CommentThread

cp-081 · Индивидуальная инструкция

## Когда выбрать

Для обсуждения с ответами, реакциями, редактированием своих сообщений и завершением ветки.

## Как применять

Передайте `currentUser`, `people`, `comments`/`onCommentsChange`; событие описывает изменение. `resolved`/`onResolvedChange` управляют завершением. `title`, `placeholder`, `reactions` и `nowLabel` настраивают содержание.

## Состояния и доступность

Компонент предоставляет локальные действия и composer; серверное сохранение, права и уведомления делает приложение. Ctrl/⌘+Enter отправляет, выбор упоминаний имеет клавиатурные альтернативы. Ошибка сети не должна терять текст обсуждения.

## Делать

- Сохранять устойчивые ID сообщений и авторов.
- Проверять права редактирования на сервере, даже если UI показывает только собственные действия.

## Не делать

- Не считать `onCommentsChange` подтверждением доставки или уведомления упомянутого пользователя.
- Не удалять ветку с ответами без продуманного поведения сохранённых данных.
