# Tag

cp-005 · Индивидуальная инструкция

## Когда выбрать

Для метки типа, категории или статуса объекта. Для нейтрального выбора фильтра используйте Chip.

## Как применять

Текст передаётся в `children`; `icon`, `count` и `counter` дополняют метку. `color` можно опустить для локального акцента. `onClick`, `onRemove` и `action` создают отдельные действия; `interactive={false}` делает все слоты статичными.

## Состояния и доступность

`disabled` блокирует и выбор, и удаление. У `action` обязательно понятное `label`. Кнопки метки и удаления независимы и имеют общую поверхность наведения.

## Делать

- Использовать одну семью Tag вместо отдельных Badge и TypeLabel.
- Для статуса писать «На проверке», сохраняя смысл без цвета.

## Не делать

- Не вкладывать собственную кнопку в кликабельную подпись.
- Не ожидать работы `onRemove`, когда явно задано `interactive={false}`.
