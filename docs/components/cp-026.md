# ObjectCard

cp-026 · Индивидуальная инструкция

## Когда выбрать

Для открытия объекта одним действием: документа, проекта, коллекции. Для независимого выбора и меню внутри карточки используйте ContentCard.

## Как применять

Укажите `title`, при необходимости `description`, `icon`, `color`, `cover` и `meta`. Открытие подключите через `onClick`; для недоступного объекта задайте `disabled`.

## Состояния и доступность

Корень — нативная кнопка, поэтому Enter и Space открывают объект. Весь контент должен оставаться неинтерактивным; название объясняет назначение. Surface родителя сохраняется, подложка — `surface/block`.

## Делать

- Помещать в `meta` краткие статичные сведения об объекте.
- Для нескольких действий переходить на ContentCard со слотами.

## Не делать

- Не вкладывать ссылку, Checkbox или кнопку удаления внутрь ObjectCard.
- Не показывать карточку активной, если открытие ещё недоступно.
