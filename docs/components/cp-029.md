# PropertyRow

cp-029 · Индивидуальная инструкция

## Когда выбрать

Для пары «свойство — значение» в карточке или инспекторе: автор, срок, статус.

## Как применять

Передайте `label`, необязательный `icon` и значение в `children`. Редактор значения может быть отдельным подходящим контролом; общая строка не сохраняет данные сама.

## Состояния и доступность

Текст свойства должен оставаться видимым. Если значение редактируется, дочерний контрол получает собственную метку; декоративная иконка не заменяет название свойства.

## Делать

- Сохранять один порядок подписей и значений в инспекторе.
- Показывать пустое значение словами, если отсутствие данных важно.

## Не делать

- Не использовать PropertyRow как кликабельную строку навигации.
- Не считать статичный `label` автоматически связанной подписью вложенного Input.
