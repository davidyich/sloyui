# TagInput

cp-068 · Индивидуальная инструкция

## Когда выбрать

Для свободного ввода нескольких коротких значений: ключевых слов, адресов или пользовательских меток.

## Как применять

Храните массив строк через `value`/`onValueChange`. `delimiter` разделяет ввод, `maxTags` ограничивает количество. Укажите `label`, при необходимости `description` и `error`; `name` связывает поле с формой.

## Состояния и доступность

Проверяйте добавление, удаление, пустую строку, дубликаты и достижение лимита. Валидацию формата, например адреса почты, выполняет приложение; компонент не отправляет приглашения.

## Делать

- Объяснять правило ввода и допустимый разделитель.
- Для известного списка использовать MultiSelect, чтобы не создавать случайные значения.

## Не делать

- Не воспринимать введённый текст как подтверждённый серверный объект.
- Не прятать причину достижения `maxTags` только в disabled-состоянии.
