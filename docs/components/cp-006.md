# Counter

cp-006 · Индивидуальная инструкция

## Когда выбрать

Для краткого количества рядом с категорией, вкладкой или действием. Для изменения числового значения используйте NumberField.

## Как применять

Передайте число или строку в `value`. `max` сокращает число, например 125 до «99+»; `variant` и `shape` подбирают оформление к родителю. В Tag используйте `count`, чтобы размер согласовался автоматически.

## Состояния и доступность

При сокращении числового значения доступное имя сохраняет полное число. Счётчик сам не является кнопкой и не объявляет каждое изменение как уведомление.

## Делать

- Сохранять видимое значение 0, если отсутствие элементов важно.
- Давать количеству контекст: «Непрочитанные» рядом с числом.

## Не делать

- Не превращать Counter в самостоятельный элемент выбора.
- Не передавать строку «125» и ожидать, что числовой `max` её сократит.
