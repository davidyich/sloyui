# MultiSelect

cp-067 · Индивидуальная инструкция

## Когда выбрать

Для выбора нескольких значений из известного списка: участников, фильтров или коллекций.

## Как применять

Передайте `options`, массив `value` и `onValueChange`. `maxVisible` ограничивает число видимых chips, а не число допустимых выборов. `label`, `description`, `error` и `emptyMessage` объясняют сценарий; `name` сохраняет отправку формы.

## Состояния и доступность

Выбранные chips нейтральные; `option.color` может обозначать категорию точкой. Проверяйте удаление с клавиатуры и disabled-варианты. Персистентность массива и ошибки сохранения — задача приложения.

## Делать

- Сохранять уникальные `value` выбранных вариантов.
- Для большой выборки использовать `maxVisible`, оставляя доступ ко всем выбранным.

## Не делать

- Не использовать устаревший `color` для окраски всех chips.
- Не принимать `maxVisible` за ограничение количества выбранных пунктов.
