# Slider

cp-023 · Индивидуальная инструкция

## Когда выбрать

Для выбора приблизительного числового значения в известном диапазоне: громкости, масштаба, интенсивности.

## Как применять

Задайте `label`, `min`, `max`, `step`, `value` и `onValueChange`. `onValueCommit` подходит для дорогого сохранения по завершении жеста. `formatValue` задаёт видимый формат и `aria-valuetext`.

## Состояния и доступность

Нативный range сохраняет управление стрелками и форму. `showValue` показывает число; для точного текстового ввода добавьте NumberField с тем же состоянием.

## Делать

- Показывать единицы, например проценты, через `formatValue`.
- Разделять живой предпросмотр и финальное сохранение через `onValueCommit`.

## Не делать

- Не требовать точного большого числа только перетаскиванием ползунка.
- Не отправлять тяжёлый запрос на каждое движение, если нужен только итог.
