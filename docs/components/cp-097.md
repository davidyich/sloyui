# BottomSheet

cp-097 · Индивидуальная инструкция

## Когда выбрать

Для модальной задачи или мобильной навигации снизу с несколькими высотами раскрытия.

## Как применять

Управляйте `open`/`onOpenChange`, задайте `title`, `variant`, `snapPoints`. Значения snap — доли высоты, индекс `snap` относится к нормализованному возрастающему списку. `onSnapChange` сохраняет выбранную высоту; `footer` содержит постоянные действия.

## Состояния и доступность

Drawer обеспечивает единственную ловушку фокуса и scroll lock. Drag начинается только с ручки, контент прокручивается нативно. Up/Down/Home/End меняют snap, Escape закрывает. `handleLabel` называет ручку.

## Делать

- Оставлять закрытие доступным кнопкой и клавиатурой.

## Не делать

- Не перехватывать прокрутку содержимого как жест перемещения sheet.
- Не передавать пиксели в `snapPoints`, которые ожидают доли 0.1–0.95.
