# RadioGroup

cp-069 · Индивидуальная инструкция

## Когда выбрать

Для выбора ровно одного из нескольких видимых вариантов с общей подписью: тарифа, способа доставки, режима доступа.

## Как применять

Передайте `options` типа RadioGroupOption, `label`, `name` и `value`/`onValueChange`. `variant="cards"` подходит для вариантов с описаниями; `layout` и `orientation` управляют композицией. У пункта можно задать `disabledReason`.

## Состояния и доступность

Варианты входят в одну нативную группу. Disabled-пункт должен иметь понятную причину; общий `error` объясняет обязательный выбор. Значение хранит приложение или форма.

## Делать

- Показывать описание, когда разницу вариантов нельзя выразить короткой меткой.
- Давать отдельным группам разные `name`.

## Не делать

- Не смешивать независимые опции в RadioGroup — нужны Checkbox.
- Не вкладывать кнопку покупки внутрь radio-карточки выбора тарифа.
