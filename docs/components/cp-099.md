# PreviewRail

cp-099 · Индивидуальная инструкция

## Когда выбрать

Для компактной навигации по нескольким объектам с быстрым предпросмотром: страницам, материалам, разделам.

## Как применять

Передайте `items`, `label`, выбранный `value`/`onValueChange`. `renderPreview` задаёт содержание, `showPreview` и `previewSide` — поведение; `highlightActive` включается явно. `onItemSelect` выполняет действие выбора.

## Состояния и доступность

Временное наведение/фокус отделены от подтверждённого выбора. Первое touch-нажатие закрепляет preview ссылки, второе переходит. Reveal прокручивает только локальную rail; пользователь должен иметь понятные подписи пунктов.

## Делать

- Использовать preview для краткого узнавания объекта перед переходом.
- Сохранять выбранный ID после окончания hover.

## Не делать

- Не обновлять основной маршрут при каждом наведении.
- Не помещать обязательные действия только в временный preview.
