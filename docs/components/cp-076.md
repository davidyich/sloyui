# JsonViewer

cp-076 · Индивидуальная инструкция

## Когда выбрать

Для чтения структуры диагностических данных, ответа API или конфигурации с раскрытием и поиском.

## Как применять

Передайте `data` и `label`; `rootName`, `defaultExpandDepth`, `pageSize`, `maxHeight` регулируют обзор. `expanded`/`onExpandedChange` управляют путями, `query`/`onQueryChange` — поиском. `onSelect` получает путь и значение.

## Состояния и доступность

Копирование управляется `copyable` и `onCopy`; поиск не изменяет данные. Проверяйте большие массивы, пустые объекты и длинные строки. Содержимое может быть публичным только после отбора приложением.

## Делать

- Ограничивать высоту и раскрытие для большого ответа.
- Показывать путь через `showPath`, когда важен адрес выбранного значения.

## Не делать

- Не использовать viewer как редактор JSON с обещанием сохранения.
- Не передавать в публичную диагностику весь ответ с приватными данными.
