# CommandPalette

cp-042 · Индивидуальная инструкция

## Когда выбрать

Для поиска и запуска команд или переходов с клавиатуры по общему набору действий.

## Как применять

Управляйте `open`/`onOpenChange`, передайте `items` типа CommandItem и понятный `placeholder`. По умолчанию `showTitle={false}`: поле поиска стоит рядом с закрытием, доступное имя сохранено. `showTitle={true}` добавляет видимый заголовок. Глобальное сочетание открытия регистрирует приложение.

## Состояния и доступность

Поиск фильтрует локальные пункты; стрелки меняют активный результат, Enter запускает, Escape закрывает. Наведение не прокручивает список; клавиатура раскрывает активный пункт локально.

## Делать

- Включать команды с различимыми названиями и проверять результат поиска без совпадений.
- Для большого серверного поиска подготовить данные в приложении до передачи.

## Не делать

- Не ожидать, что компонент сам зарегистрирует ⌘K.
- Не смешивать временное наведение и окончательно выбранную команду.
