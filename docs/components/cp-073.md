# RichTextEditor

cp-073 · Индивидуальная инструкция

## Когда выбрать

Для структурированного документа с блоками, форматированием, списками и контекстными действиями.

## Как применять

Храните `RichTextDocument` через `value`/`onValueChange`, задайте `label`. `uiVariant="classic"` показывает обычный toolbar, `"context"` — форматирование выделения. Для Markdown используйте экспортируемые bridge helpers, сохраняя `block.markdown`.

## Состояния и доступность

`readOnly` оставляет чтение, `disabled` запрещает редактирование. `onCommentRequest` передаёт выделенный текст приложению без создания обсуждения. Неподдерживаемый Markdown остаётся редактируемым исходником.

## Делать

- Сохранять стабильную структуру документа и исходные Markdown-метаданные.
- Проверять вставку, выделение, undo и сохранение на реальном длинном тексте.

## Не делать

- Не считать визуальное преобразование точным round-trip для произвольного Markdown без метаданных.
- Не запускать комментарий на сервере только потому, что открыт contextual-toolbar.
