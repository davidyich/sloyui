# Accordion

cp-033 · Индивидуальная инструкция

## Когда выбрать

Для раскрываемого раздела с дополнительным содержимым или группы боковой навигации.

## Как применять

Передайте `title` и содержимое, начальное раскрытие — через `defaultOpen`. `onOpenChange` сообщает изменение. `variant="navigation"` подходит для группы меню; `expandLabel` и `collapseLabel` уточняют действие.

`chevronPosition="end"` помещает шеврон справа: вниз в закрытом состоянии и вверх в открытом. По умолчанию `start` сохраняет прежнее поведение; у `bouncy` шеврон остаётся справа. Переход меняет точки SVG без вращения.

## Состояния и доступность

Раскрытие доступно клавиатурой и выражено через expanded-состояние. Проверяйте доступность скрываемого контента и сохранение фокуса; `bouncy` не должен быть обязательным для понимания.

## Делать

- Открывать по умолчанию раздел с текущим выбором или важной ошибкой.
- Группировать связанную навигацию одним заголовком.

## Не делать

- Не прятать единственную кнопку отправки формы в закрытом разделе.
- Не вкладывать собственную кнопку в интерактивный заголовок.
