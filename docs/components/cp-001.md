# Button

cp-001 · Индивидуальная инструкция

## Когда выбрать

Для действия: сохранить форму, создать объект, подтвердить выбор. Для перехода по адресу используйте TextAction с `href`.

## Как применять

Передайте текст в `children`, действие в `onClick`, важность через `variant`. Для отправки формы укажите `type="submit"`; по умолчанию это `button`. `leading` и `trailing` дополняют подпись.

У любой кнопки без видимого текста обязательна компактная Tooltip с названием действия из её доступного имени (`aria-label` или `aria-labelledby`). Button и IconButton показывают её автоматически через 350 ms наведения или сразу при клавиатурном фокусе, сохраняя DOM кнопки и disabled-состояние. Для стандартного действия с иконкой используйте IconButton с `label`. Явная Tooltip заменяет автоматическую; `title` не дублирует подсказку.

## Состояния и доступность

`loading` показывает ожидание и блокирует повторную активацию; `disabled` запрещает действие. Нативная кнопка работает с Enter и Space; ошибка операции остаётся рядом с результатом.

## Делать

- Выделять главное действие через `primary` или локальный `accent`.
- Сохранять подпись «Сохранить» во время запроса и включать `loading`.

## Не делать

- Не оформлять все действия одной формы как главные.
- Не передавать `href` в Button и не заменять текст непонятной иконкой.
