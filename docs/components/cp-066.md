# ComboBox

cp-066 · Индивидуальная инструкция

## Когда выбрать

Для выбора одного значения из большого списка с поиском: участника, проекта, категории.

## Как применять

Передайте `options` типа SelectionOption, `label`, `value`/`onValueChange`. `clearable` разрешает очистку, `emptyMessage` объясняет отсутствие совпадений. `name` сохраняет форму; `description` и `error` поясняют поле.

## Состояния и доступность

Выбранное значение и строка поиска имеют разный смысл. Проверяйте стрелки, Enter, Escape, пустой результат и disabled-пункты. Загрузка вариантов остаётся в приложении.

## Делать

- Добавлять aliases к вариантам, если пользователь ищет сокращённое название.
- После очистки сохранять пустой выбор, когда поле необязательно.

## Не делать

- Не считать произвольный поисковый текст новым значением списка.
- Не сбрасывать подтверждённый выбор из-за запроса, не давшего совпадений.
