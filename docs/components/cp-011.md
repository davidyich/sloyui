# Avatar

cp-011 · Индивидуальная инструкция

## Когда выбрать

Для пользователя или участника обсуждения, когда важна его личность.

## Как применять

Передайте обязательное `name`, необязательное `src` и `size`. Без изображения компонент показывает инициалы. Проверяйте URL изображения в приложении и снимайте `src` при недоступном ресурсе.

## Состояния и доступность

Корневой элемент имеет `role="img"` и имя из `name`; внутреннее изображение не дублирует его. Avatar не является действием и не управляет загрузкой профиля.

## Делать

- Передавать полное имя, даже если рядом видны только инициалы.
- Для ссылки на профиль оборачивать аватар в понятную ссылку с учётом дублирования имени.

## Не делать

- Не ожидать автоматического возврата к инициалам при ошибке `src`.
- Не использовать одинаковое имя «Пользователь» для всех участников.
