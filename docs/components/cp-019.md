# Field

cp-019 · Индивидуальная инструкция

## Когда выбрать

Для общей подписи и описания нестандартного поля, которому нужна связь label/id/error. Input, Select и Textarea уже имеют собственные подписи.

## Как применять

Передайте `label`, `hint`, `error`, при необходимости `required`. В render prop используйте полученные атрибуты для дочернего контрола, сохраняя id и связи с описанием.

## Состояния и доступность

Один доступный контрол должен соответствовать одной подписи. Ошибка привязывается через описание и invalid-состояние; отметка required не заменяет реальное ограничение в поле.

## Делать

- Использовать render prop для связи самописного контрола с подписью.
- Объяснять ошибку текстом рядом с нужным полем.

## Не делать

- Не добавлять Field вокруг Input с уже заданным одинаковым `label`.
- Не оставлять визуальную подпись без `htmlFor` или эквивалентной связи.
