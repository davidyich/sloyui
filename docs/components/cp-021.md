# Radio

cp-021 · Индивидуальная инструкция

## Когда выбрать

Для одного выбора среди нескольких явно видимых вариантов. Для готовой группы с общей подписью используйте RadioGroup.

## Как применять

Передайте `label`, `value`, общее `name` и `checked`/`onChange`. Разные группы получают разные `name`; значение выбора сохраняет приложение или форма.

## Состояния и доступность

Нативные radio поддерживают клавиатурный переход внутри группы. `disabled` применяется к недоступному варианту; объяснение причины оставьте видимым рядом.

## Делать

- Объединять варианты одной задачи общим `name`.
- Сохранять выбранное значение после повторного рендера формы.

## Не делать

- Не давать каждому варианту одной группы отдельное имя.
- Не включать одновременно несколько `checked` в одну группу.
