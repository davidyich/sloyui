# InlineComments

cp-082 · Индивидуальная инструкция

## Когда выбрать

Для комментариев, привязанных к месту в визуальном материале: макете, изображении или стабильном canvas.

## Как применять

Передайте содержимое в `children`, `currentUser`, `anchors`/`onAnchorsChange`. Якорь хранит ID, нормализованные `x`/`y` от 0 до 1 и обсуждение. `commentMode`/`onCommentModeChange` управляют размещением.

## Состояния и доступность

Пины — подписанные кнопки; popup содержит CommentThread. Enter/Space размещают якорь по центру, Escape отменяет режим. Координаты не являются устойчивой текстовой привязкой после изменения содержимого.

## Делать

- Сохранять координаты относительно того же материала и его версии.
- Проверять доступность открытия пина с клавиатуры и при изменении размеров.

## Не делать

- Не использовать x/y как привязку к абзацу, который постоянно меняется.
- Не считать размещение комментария автоматическим сохранением на сервере.
