# Spinner

cp-004 · Индивидуальная инструкция

## Когда выбрать

Для краткого ожидания, когда длительность и процент выполнения неизвестны. Для известного процента выберите Progress.

## Как применять

Укажите `label` с конкретной операцией: «Загрузка файлов». Размер и положение задаёт композиция; Spinner не запускает запрос и не управляет его состоянием.

## Состояния и доступность

Компонент объявляет ожидание через `role="status"`. Уберите его после завершения; при ошибке покажите объяснение и доступное повторное действие.

## Делать

- Привязывать индикатор к области, которая действительно загружается.
- Для ожидания кнопки использовать её `loading`, чтобы блокировать повторный запуск.

## Не делать

- Не оставлять бесконечный индикатор после ошибки.
- Не показывать Spinner вместе с выдуманным процентом выполнения.
