# Callout

cp-031 · Индивидуальная инструкция

## Когда выбрать

Для пояснения рядом с содержимым: ограничения, совета или причины ошибки, которую нужно прочитать в контексте.

## Как применять

Передайте краткий `title`, текст в `children`, при необходимости `icon` и `color`. Доступное действие можно добавить в содержимое отдельной Button или TextAction.

## Состояния и доступность

Статичный Callout не заменяет срочное объявление ошибки. Важная информация должна быть выражена текстом; цвет и иконка только усиливают смысл.

## Делать

- Объяснять ограничение и следующий шаг: «Нет доступа — запросите роль редактора».
- Оставлять пояснение рядом с функцией, к которой оно относится.

## Не делать

- Не использовать Callout для каждого обычного абзаца.
- Не прятать обязательное подтверждение опасного действия в статичном пояснении.
