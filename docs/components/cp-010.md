# IconBox

cp-010 · Индивидуальная инструкция

## Когда выбрать

Для узнаваемого символа объекта на небольшой цветной подложке: документ, папка, тип записи.

## Как применять

Передайте `icon`, выберите `size`. Опущенный `color` наследует локальный акцент; явный `color` нужен для постоянной категории. Контейнер не выполняет действие.

## Состояния и доступность

Сам символ декоративный; название объекта должно быть текстом рядом. Для клика используйте доступную кнопку в композиции, а не только обработчик на подложке.

## Делать

- Согласовывать цвет IconBox и Tag, когда они обозначают один тип.
- Сохранять нейтральную подложку для объектов без цветовой классификации.

## Не делать

- Не заменять Avatar цветной иконкой для реального пользователя.
- Не превращать IconBox без подписи в кнопку открытия объекта.
