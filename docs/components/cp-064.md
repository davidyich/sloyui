# NavigationMenu

cp-064 · Индивидуальная инструкция

## Когда выбрать

Для основной горизонтальной навигации приложения с текущим разделом и дополнительными слотами.

## Как применять

Передайте `items` типа NavigationMenuItem, `activeId`, `label`. `leading` и `trailing` принимают отдельный бренд или действие; `size` согласует высоту. Маршруты и обработку переходов задаёт приложение.

## Состояния и доступность

Активный раздел соответствует маршруту. Проверяйте фокус, раскрытие дочерних пунктов и длинные подписи на узкой ширине; наведение не должно менять текущую страницу.

## Делать

- Сохранять стабильные ID разделов и понятные ссылки.
- Размещать действия аккаунта в отдельном trailing-слоте.

## Не делать

- Не отмечать наведённый пункт активным вместо текущего маршрута.
- Не использовать основное меню для всех команд редактирования документа.
