# HoverPanel

cp-065 · Индивидуальная инструкция

## Когда выбрать

Для дополнительного предпросмотра объекта возле подписанного инициатора: кратких данных проекта или пользователя.

## Как применять

Передайте `label`, `summary` и подробности в `children`. При необходимости управляйте `open`/`onOpenChange`; `openDelay` и `closeDelay` регулируют появление. Сохранение и открытие объекта выполняет приложение.

## Состояния и доступность

Предпросмотр должен быть доступен при фокусе, а не только мышью. Основная информация остаётся у объекта; на сенсорном экране нужен понятный способ открытия без hover.

## Делать

- Использовать summary, достаточное для понимания объекта без preview.
- Проверять переход фокуса и указателя между инициатором и панелью.

## Не делать

- Не помещать единственную обязательную кнопку действия в hover-only содержание.
- Не превращать краткий preview в длинную модальную форму.
