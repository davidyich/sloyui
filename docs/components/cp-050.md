# StatusBar

cp-050 · Индивидуальная инструкция

## Когда выбрать

Для постоянного краткого состояния рабочей области: синхронизации, количества объектов, текущей операции.

## Как применять

Передайте основное содержимое и слоты `leading`/`trailing`, `busy` на время работы. `variant="plain"` оставляет прозрачный фон, `"surface"` рисует подложку; `tone` и `appearance` уточняют состояние.

## Состояния и доступность

Компонент использует polite-status. При neutral-оформлении цвет статуса ограничен иконкой; текст должен объяснять результат. Частые обновления не должны превращаться в непрерывные объявления.

## Делать

- Сохранять стабильное место статуса, например «Сохранено» рядом с редактором.
- Использовать `busy` для реальной синхронизации и показать ошибку при её отказе.

## Не делать

- Не помещать длинное сообщение с обязательным подтверждением в тесную строку.
- Не показывать «Сохранено», пока запрос ещё не завершился.
