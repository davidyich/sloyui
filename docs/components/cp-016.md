# Input

cp-016 · Индивидуальная инструкция

## Когда выбрать

Для одной строки текста: названия, почты, поиска. Для даты, числа и цвета выбирайте специализированные компоненты.

## Как применять

Используйте `label`, `hint`, `error` и `labelPlacement="outside"` или `"inside"`. Controlled-значение связывайте через `value` и `onChange`; `name` сохраняет участие в форме. `leading` и `trailing` — слоты, не вторая подпись.

## Состояния и доступность

Ошибка связывается с полем; `disabled` запрещает ввод, `readOnly` оставляет чтение. `placeholder` только пример, а не доступная метка. Сохранение текста и валидацию выполняет приложение.

## Делать

- Передавать одну подпись через `label`, не дублируя её в Field.
- Проверять длинное значение, очистку и ошибку после отправки.

## Не делать

- Не использовать `type="date"` или `type="color"` для готового интерфейса.
- Не скрывать ошибку только изменением цвета границы.
