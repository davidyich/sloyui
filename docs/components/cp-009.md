# IconPicker

cp-009 · Индивидуальная инструкция

## Когда выбрать

Для выбора иконки пользователем в настройках объекта, команды или интерфейса.

## Как применять

Укажите `label`, храните выбранное имя через `value` и `onValueChange`. `variant="grid"` подходит для открытой галереи, `combobox` — для компактного выбора; `options` ограничивает допустимый набор.

## Состояния и доступность

`disabled` блокирует выбор. Проверяйте поиск по именам и понятность текущего значения; оставляйте видимый фокус и достаточные зоны нажатия для ячеек.

## Делать

- Предлагать визуальную галерею с поиском вместо списка строк.
- Сохранять выбранное имя, которое действительно входит в `options`.

## Не делать

- Не показывать весь набор без поиска в тесной форме.
- Не заменять IconPicker текстовым Input с произвольным названием Lucide.
