# Menu

cp-040 · Индивидуальная инструкция

## Когда выбрать

Для набора команд над объектом или рабочей областью: открыть, дублировать, удалить.

## Как применять

Укажите `label` триггера и `items` типа MenuItem. `icon` или `triggerContent` меняют триггер; `size` согласует его с панелью. Для выбора значения формы используйте Select.

## Состояния и доступность

Стрелки, Home/End и поиск по первым буквам обходят enabled-пункты; Escape возвращает фокус к триггеру. Наведение не является текущим выбором. Доступность операций определяет приложение.

## Делать

- Разделять недоступные команды и рабочие действия с объяснимой причиной.
- Писать команды глаголом и указывать объект опасной операции.

## Не делать

- Не применять Menu вместо поля выбора с сохраняемым значением.
- Не собирать меню из произвольных кликабельных div, обходя MenuItem.
