# Dialog

cp-037 · Индивидуальная инструкция

## Когда выбрать

Для короткой задачи, требующей отдельного внимания: подтверждения, создания объекта, редактирования ограниченного набора полей.

## Как применять

Управляйте `open` и `onOpenChange`; задайте `title`, при необходимости `description`, `footer` и `size`. `dismissOnOutside` выбирайте по риску потери черновика; сохранение данных выполняет приложение.

## Состояния и доступность

Компонент сам создаёт портал, ловушку фокуса, inert-фон, блокировку прокрутки и восстановление фокуса. Escape закрывает диалог. Ошибка сохранения должна оставить форму и введённые значения.

## Делать

- Показывать конкретное действие подтверждения: «Удалить проект».
- Закрывать после успешного сохранения, сохраняя ошибки внутри формы.

## Не делать

- Не добавлять вторую ловушку фокуса или отдельный scroll lock.
- Не открывать Dialog для каждого несущественного уведомления.
