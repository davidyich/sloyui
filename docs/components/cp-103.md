# FileCard

cp-103 · Индивидуальная инструкция

## Когда выбрать

Для вложения с узнаваемым типом, размером и независимыми действиями открытия, скачивания и удаления.

## Как применять

Передайте `name` и готовый `sizeLabel`; `mimeType` помогает определить тип, явный `kind` имеет приоритет. `thumbnail` необязателен. Действия задавайте через `href`/`onOpen`, `downloadHref`/`onDownload`, `onRemove`; URL и эффекты хранит приложение.

## Состояния и доступность

`loading` и `disabled` блокируют действия; при ошибке thumbnail показывается плитка формата. Кнопки независимы. Surface родителя сохраняется, подложка — `surface/block`. `thumbnailAlt` нужен, если preview несёт отдельный смысл.

## Делать

- Форматировать размер файла до передачи в компонент.
- Для удаления сохранять возможность понятной отмены или подтверждения по сценарию.

## Не делать

- Не вкладывать весь FileCard в кнопку поверх его собственных действий.
- Не показывать URL скачивания, который приложение ещё не получило.
