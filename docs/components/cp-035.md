# Table

cp-035 · Индивидуальная инструкция

## Когда выбрать

Для небольшой статичной таблицы без встроенной сортировки, поиска и пагинации. Для управления данными выберите DataTable.

## Как применять

Передайте `columns` как подписи столбцов, `rows` как массивы ячеек и `caption` для назначения таблицы. Содержимое ячеек может быть ReactNode; подготовка и порядок строк — задача приложения.

## Состояния и доступность

Сохраняйте логическое соответствие колонок и ячеек. Проверяйте горизонтальную прокрутку на узком экране и подписи интерактивных элементов внутри ячеек.

## Делать

- Использовать таблицу для сопоставимых значений с общими колонками.
- Задавать caption, объясняющий набор данных.

## Не делать

- Не ожидать автоматической сортировки от клика по заголовку.
- Не строить визуальную сетку карточек через Table без табличных отношений.
