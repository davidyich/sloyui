# Что не повторять

| Ошибка | Вместо неё |
| --- | --- |
| Сокращённая палитра `kit` или literal цвета в компонентах | Полные исходные палитры и общие семантические роли |
| Light · Base и Dark · Raised как один переключатель Figma | Независимые коллекции Theme и Semantic |
| Серый непрозрачный hover внутри цветного блока | Нейтральная alpha-реакция поверх цвета |
| Одинаковая жёсткая рамка для всех объектов | Оттенок по поверхности и роли; общий primitive ширины |
| Отключение фокуса вместе с декоративной рамкой | Независимый значимый индикатор |
| Поверхность определяется по DOM-цвету | Явный `data-surface` и соответствующая заливка |
| Вложенные одинаковые поверхности сливаются | Card всегда имеет структурный контур; другим дочерним блокам явно задайте `.cap-surface-boundary`, видимый при Borders Off |
| Кнопки вплотную, растянутые цветовые кружки | Зазор 2–4 px; кругу фиксированные равные размеры и flex-shrink: 0 |
| Отдельные реализации Badge, Tag и TypeLabel | Один Tag с вариантами, иконкой, count и action |
| Подчёркивание интерфейсной ссылки на hover | TextAction с alpha-подсветкой области |
| Разные высоты контролов одной строки | Общая шкала control-size; проверка реальных bounding boxes |
| Одинаковый радиус вложенных прямоугольников | Внутренний радиус = внешний минус отступ |
| Сильное скругление сжимает текст у края | Общий `--cap-radius-inset` увеличивает боковые отступы текстовых кнопок, полей и пунктов меню; иконки и внутренние подписи смещаются вместе с текстом |
| Панель параметров сливается со страницей без обводок | Встраивать Raised-панель внутрь Canvas-рамки песочницы с отступом 8 px; сохранять видимый фон рамки независимо от поверхности образца |
| Выбранный сегмент невидим после первого открытия | Измерять слой выделения после подключения родительского ref; повторять измерение при resize, включая изменение ширины выбранного текста |
| Горизонтальная палитра блокирует прокрутку страницы над цветом | Для горизонтального viewport оставлять `overscroll-behavior-y:auto`; проверять реальный wheel над образцом в обоих видах |
| Hover-область образца имеет другое скругление | Радиус контейнера = радиус цветного чипа + его внутренний отступ; оба следуют общей шкале |
| Выделение меню прыгает между строками | Один общий hover-слой по transform внутри своей группы; выбранная навигация остаётся отдельным статичным состоянием. Учитывать resize и reduced motion |
| Боковая панель блокирует соседний документ | ContentLayout для параллельной работы; Drawer для модальности |
| Голый pre в API или примере | CodeBlock с выбором языка, необязательным label и копированием |
| Тень плавающего элемента обрезана overflow или маской | Выносить панель в отдельный слой: `ScrollArea.floating`; оставлять место для тени и резерв под контент. Не снимать clipping у самого scroll viewport |
| Панель настроек теряет фон при смене поверхности превью | Собственный `data-surface="raised"` и `--cap-surface-current`; не наследовать контекст образца |
| Выбор иконки обычным Select без поиска и рисунка | `IconPicker variant="combobox"`, визуальные результаты и keywords с алиасами |
| Внешний scroll страницы поверх прокрутки контентной панели | Один владелец вертикальной прокрутки; `min-height: 0` в flex/grid-цепочке; проверка `document.scrollHeight <= viewport` |
| Скрытый SR-only элемент растягивает страницу | Явные inset у absolute helper и локальный позиционированный контейнер; `clip-path` сам по себе не ограничивает scroll bounds |
| CodeBlock упирается в край API-карточки | Равные боковые и нижний отступы (в каталоге 16 px); проверять раскрытое состояние и длинный код на 320 px |
| Горизонтальная карточка растянута по высоте соседней вертикальной | `align-items: start` / `align-self: start`; обложка следует своей карточке |
| Поля имеют разные реализации внутренней подписи | Общий `labelPlacement`, один источник label, связанный hint/error |
| Ghost-поле становится неразличимым при наведении или фокусе | Прозрачный idle и `--cap-control-hover` для реакции; label, error и focus сохраняются |
| Группа случайно наследует акцент или hover не связан с её заливкой | Оставлять нейтральный `ButtonGroup` по умолчанию; для локального акцента явно ставить `color="inherit"`, для другого — его цвет. Нейтральные реакции брать из канонических `group/hover`, `group/selected` и `group/pressed` |
| Pill-форма Tag выглядит зажатой по бокам; маленький счётчик растянут | `Tag.shape="pill"` использует больший inset; компактный Counter сохраняет малые боковые отступы и минимальную ширину по высоте |
| Разные компоненты переопределяют глобальный радиус вручную | Задавать ближайший `data-radius="compact" | "default" | "rounded"`; порталы уже наследуют контекст |
| Меню вложено в предка с `overflow:hidden` и обрезается | Использовать anchored portal с зазором 12 px, переворотом и viewport clamp |
| Видимый браузерный spinner или picker в готовом UI | Использовать `NumberField`, `DatePicker`, `ColorPicker` или `Select`/`ComboBox`; скрытая нативная подложка для семантики и формы допустима |
| Форматирование или выбор диапазона доступно только мышью | Оставлять клавиатурный способ; для значения использовать `ValueScrubber` с Alt+drag и arrow/Home/End |
| График сообщает данные только цветом или SVG-формой | Дать понятную подпись, клавиатурный выбор и доступную таблицу исходных значений |
| RichTextEditor используют как HTML-контейнер | Хранить только JSON-блоки, stable IDs и известные marks; произвольную HTML-модель проектировать отдельно |
| Яркая акцентная иконка пустого состояния | Нейтральная декоративная иконка тише текста; при необходимости без иконки |
| Перестановка только drag-and-drop или за всю интерактивную карточку | Ручка ReorderableList; стрелки клавиатуры и кнопки; постоянные ID |
| Новый focus trap вокруг Dialog, Drawer или BottomSheet | Встроенная модальность и восстановление фокуса |
| Ручная правка generated tokens | Изменение source/generator, затем `npm run tokens` |
| Markdown теряется после rich-редактирования | Markdown-мост с исходными metadata; неподдержанные конструкции сохранять исходными блоками — [editor-revision.md](editor-revision.md) |
| Статусный цвет перекрашивает действия нейтрального сообщения | Ограничить hue статусной иконкой; `appearance="soft|solid"` задавать явно — [feedback-revision.md](feedback-revision.md) |
| Раскрытый стек перекрывается или обрезается | Измеренные размеры элементов и `expandDirection`, локальная прокрутка — [feedback-revision.md](feedback-revision.md) |
| Переименование компонента меняет ID или теряет вторую группу | Постоянный ID и все `groups` в [component-registry.md](component-registry.md) |
| Длинные дублирующие инструкции | Одно каноническое правило и ссылки из остальных документов |

Не объявляйте Figma обновлённой по одному JSON-экспорту: нужна подтверждённая запись в документ. Проверку статической сборки не называйте проверкой сохранения файлов.

Не добавляйте крестикам Tag отдельную hover-плашку. Не включайте реакцию статичного Tag. Не ограничивайте Counter фиксированной шириной: одно число помещается в квадрат, длинное расширяет его. Не используйте один яркий фон для hover и выбранного пункта меню.


## Глобальные настройки и демонстрационные островки

- Не ставьте `:root` с обычным режимом после селектора `data-radius="compact"`: равная специфичность перезаписывает минимальный режим. Сначала объявляется default, затем явные режимы. Проверяйте все три режима и на `html`, и на локальном фрейме.
- Фиксированные радиусы в оболочке каталога, карточках и образцах разрывают общую настройку. Используйте radius-токены; круги и явно выбранная форма pill сохраняют свою геометрию.
- Выбранная поверхность образца не должна перекрашивать всю страницу документации: применяйте её к островкам preview, и блоку «Использование в коде», а контекст оболочки и параметров сохраняйте постоянным.
- Панель инструкций должна иметь Raised-фон и `.cap-surface-boundary` при Borders Off. Длинные имена файлов в навигации сокращайте только до расширения: основа с ellipsis, `.md` остаётся видимым; полный путь или имя оставляйте в `title`.
- Не сжимайте связанные действия FloatingActionBar до случайного переноса одной кнопки. Контейнер сравнения должен переходить в одну колонку до того, как панели не хватает ширины.

## Заливки, код и раскрытие

- Не стилизуйте общий класс `.cap-radio` из файла RadioGroup глобально. Селекторы RadioGroup ограничивайте `.cap-radio-group`, чтобы не менять заливку, размеры, фокус и disabled самостоятельного Radio.
- Не назначайте чёрный или белый знак по теме либо флагу `contrast`. Генератор сравнивает контраст обоих цветов с конкретным оттенком Primary, выбирает более читаемый и проверяет ту же пару на hover/pressed.
- Не заливайте compound-строку нейтральной парой самостоятельного контрола: это поглощает вложенные secondary-элементы. Используйте reaction-роли и структурную границу вложенной метки; контракт — `surface-context.md`.
- Не скрывайте границу вложенных одинаковых поверхностей вместе с декоративными обводками. `cap-surface-boundary` сохраняет структурную границу; `Card` включает её сам.
- Не удаляйте раскрытое содержимое в первый кадр закрытия. Дайте переходу завершиться, сразу исключив закрываемые элементы из фокуса; быстрый обратный клик должен разворачивать текущий переход. `prefers-reduced-motion` отключает движение.
- Не подсвечивайте все языки одной регуляркой и не вставляйте исходник как HTML. `CodeBlock` использует отдельные правила языка, сохраняет исходную строку и даёт режим Plain text без подсветки.

- Не задавайте кольцо фокуса разными несвязанными стилями на полях одного семейства. Используйте общий `focusRing` и наследуемые field-focus переменные; при отсутствии prop не сбрасывайте локальный контекст.
- Не вызывайте focus() после pointer-выбора, если фокус уже на триггере. Это может ошибочно включить клавиатурное кольцо; Escape и реальные переходы фокуса должны оставаться доступны.
