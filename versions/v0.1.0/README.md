# Capacities UI 0.1.0 — frozen baseline

Saved before the V2 update on 2026-10-04. Neither archive is regenerated by the build.

- `workspace.tar.gz`: source, demo, docs, tests, built library and built catalogue. Excludes `.git`, `node_modules`, `versions`, and transient `artifacts`.
- `personal-capacities-ui-0.1.0.tgz`: the original installable package.

Verify: `shasum -a 256 -c SHA256SUMS` from this directory.

Preview/restore safely in a separate directory (the current V2 checkout stays intact):

```sh
mkdir -p /tmp/capacities-ui-v1
tar -xzf versions/v0.1.0/workspace.tar.gz -C /tmp/capacities-ui-v1
cd /tmp/capacities-ui-v1
npm ci
npm run dev -- --port 4318
```

Consumer rollback: install `versions/v0.1.0/personal-capacities-ui-0.1.0.tgz` in the consuming project. The lockfile pins that version.
