# Sloy UI — runtime и совместимые пути токенов

Этот документ описывает canonical/runtime-модель, включая совместимые внутренние пути и Glass. Для нового native Figma-файла используйте [актуальный дизайнерский гайд](../color-system-v2/designer-guide.md): в нём пять Surface modes и компактный native export без числовой Opacity-коллекции.

Начните с задачи объекта: фон, текст, граница или размер. Затем выберите режим.
Структура учитывает UNIDES Collection. Нейтральные поверхности используют предоставленный образец Codex.
Откройте [интерактивные примеры](./explorer.html), чтобы проверить выбор и скопировать точное имя токена.

## 1. Выберите поверхность по назначению

| Режим Surface | Назначение |
| --- | --- |
| Shell | Оболочка приложения и общая навигация. |
| Workspace | Список, боковая панель или рабочая область. |
| Content | Основной документ или редактор. |
| Overlay | Всплывающее меню, popover или диалог. |
| Invert | Чёрная область в Light, белая в Dark, со своими парами. |
| Glass | Защищённая прозрачная область на текстуре. |

Выберите режим `Surface` на контейнере области. Не определяйте поверхность по числу вложенных контейнеров.
Для дочерних объектов оставьте режимы на `Auto`, если объект не создаёт другую поверхность.
На общем родителе задайте `Theme`: `Light` или `Dark`.
`SurfaceScheme/Standard` и `Dimmed` выбирают полные контексты областей в обеих темах. В Dark меняются Shell, Workspace, Content и Overlay; в Light меняется Workspace. Точные фоны повторяют Figma-референсы. Inverted — совместимое имя Dimmed.

## 2. Окрасьте область и блок внутри неё

1. Привяжите фон области к `Theme/surface/bg`.
2. Для локального блока выберите `Theme/surface/block`.
3. Переключите Surface и проверьте оба цвета.

Блок сохраняет контекст родителя. Не задавайте блоку новый Surface только из-за его заливки.
Для обычного текста выберите роль из `Theme/content`: `primary`, `secondary`, `tertiary`, `muted` или `caption`.

## 3. Соберите secondary-объект

Выберите оттенок: `neutral` или один из шести акцентов: blue, green, orange, red, pink, purple. Используйте один оттенок для всей пары.

1. Для заливки выберите `Theme/surface/secondary/<hue>-normal`.
2. Для текста и иконки выберите `Theme/content/<hue>`.
3. Для нужной границы выберите `Theme/border/<hue>-normal`.

При наведении используйте `hover`, при нажатии — `pressed`. Меняйте состояние заливки и границы вместе.
Для вложенного действия используйте те же hover и pressed. Не добавляйте светлый прозрачный слой поверх secondary-заливки. На цветной заливке используйте парный content/<hue>; обычные content-роли предназначены для нейтрального фона.
Проверьте объект на всех шести поверхностях. Secondary/Tertiary используют алиас пигмента из 41-ступенчатой шкалы и числовой alias Opacity. Контраст считается после композиции на bg и block. Hover и pressed акцентов ссылаются на один active-токен.

## 4. Выделите главное действие

1. Выберите заливку `Theme/surface/primary/<hue>-normal`.
2. Выберите текст `Theme/content/on-primary/<hue>`. Для neutral используйте `Theme/content/on-primary`.
3. Проверьте состояния `hover` и `pressed` в обеих темах.

`on-primary/<hue>` соответствует конкретному акценту; цвет задаёт политика акцента, а заливка адаптируется под контраст. Для недоступного контента используйте `Theme/content/disabled`.
Не подменяйте текст основного действия произвольным белым или чёрным цветом.

## 5. Сохраните цвет при смене темы

Для постоянного цвета выберите токен из `Theme/stable/neutral`, `Theme/stable/accent` или `Theme/stable/alpha`.
Переключите Light и Dark. Значение выбранного stable-токена должно остаться прежним.
Stable полезен для графики, которой нужен постоянный цвет. Обычный текст интерфейса использует контекстные роли `content`.
Проверьте контраст stable-цвета на нужном фоне. Постоянный цвет не гарантирует читаемость на любой поверхности.
Для alpha доступны 20 процентов от 3 до 96. `adaptive/alpha/base-*` — white в Light и black в Dark; `contrast-*` — наоборот. Surface не меняет adaptive alpha. Для локальных контролов Invert выбирайте контекстную surface-пару.
У `stable/alpha` постоянны цвет и прозрачность. Итоговый вид зависит от фона под образцом.

## 6. Настройте плотность без уменьшения текста

Выберите роли из `Density/adaptive/padding` для внутренних отступов, `adaptive/gap` для промежутков и `adaptive/control` для размеров контролов.
Если размер должен сохраняться, выберите роль из `Density/fixed/space` или `fixed/size`.
Переключите `Density` между `Default` и `Compact`. Adaptive перестраивает геометрию; Fixed сохраняет значение.

Адаптивное значение: `round(k × u)`. Единица `u` равна 4 px в Default и 3 px в Compact.
Высота контрола: высота строки текста плюс два вертикальных отступа. Размер текста и высота строки не меняются.
Сохраняйте область нажатия не менее 44 px, даже если видимый контрол меньше.

## 7. Измените скругления и декоративные границы

Выберите `Radius`: `None`, `Compact`, `Default` или `Rounded`. Базовые радиусы равны 0, 4, 8 и 16 px.
Привяжите углы к подходящей роли Radius. Переключение Radius не меняет Density.
Для общих границ выберите `Theme/border/subtle`, `default` или `strong`. Для фокуса выберите `Theme/border/focus`.
Режим `Borders/Off` скрывает только декоративные границы. Индикатор фокуса должен оставаться видимым.
Проверьте вложенные углы после смены плотности: отступ влияет на согласование внешнего и внутреннего радиуса.

## 8. Выберите шрифт по роли

| Токен Primitives | Значение |
| --- | --- |
| font/family/base | Inter |
| font/family/code | Overpass Mono |
| font/family/heading | Georgia |
| font/family/pair | Courier New |

Выберите family, размер, высоту строки, начертание и межбуквенный интервал из `Primitives/font`.
При замене гарнитуры измените значение роли. Сохраните имя роли.
Проверьте текст в обоих режимах Density. Типографика должна сохранить значения.

Исходные цвета находятся только в Palette, исходные числа и шрифты — в Primitives. Opacity содержит числовые алиасы процентов. Полупрозрачная COLOR-переменная соединяет алиас цвета с алиасом Opacity. Остальные коллекции используют ссылки на другие коллекции.

Для инверсной области задавайте Surface/Invert без вложенной смены Theme. SurfaceScheme/Standard и Dimmed остаются независимыми схемами областей; Inverted — совместимое имя Dimmed. Glass использует белый 88% / чёрный 80%; изменение этих значений требует проверки текста на чёрной и белой подложках. Blur не заменяет защитную заливку.
Palette содержит одну непрозрачную шкалу на цвет: например, `blue/01…41`. Light и Dark, Primary и Secondary, текст и поверхности выбирают ступени из этой общей шкалы. Прозрачность принадлежит роли и ссылается на Opacity. Например, `Theme/stable/alpha/black-32` соединяет `Palette/black` и `Opacity/32`. Новые HEX для отдельных ролей и дополнительные RGB-шкалы запрещены.
В интерфейсе применяйте готовые роли. Не копируйте исходное значение вместо привязки.

Текст использует принципы ясного письма ASD-STE100. Это русская адаптация, а не заявление соответствия английскому стандарту.
